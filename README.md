## フォルダ構成

章ごとに `Chapter01`〜`Chapter11` のフォルダがあり、その章で使うデータ(CSV・Excel)と notebook(.ipynb)が入っています。

11章は OpenAI の API キーが必要です(利用は有料)。

本リポジトリのデータは本書の学習用に作成した架空のデータで、実在の企業・個人とは関係ありません。
